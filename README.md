# ARG 快贴板（QuickPad）

一个给 ARG / 解谜游戏玩家用的「选中即记录 + 随手复制」浮窗工具。

## 直接使用

双击 **`ARG快贴板.exe`** 即可

## 核心用法

- **选中文字按快捷键记录**：在任何程序里选中一段文字，按 `F9`（默认），选中的内容就会被记录下来。不用再手动复制粘贴。
- **快捷键可以改**：点窗口里的「抓取键：F9」按钮，或右上角 `☰` →「设置抓取快捷键…」，然后直接按下你想要的键。建议用单个按键（F8 / F9 / F10 最顺手），也可以加 Ctrl / Shift / Alt。
- **双击即复制**：双击列表里的某条，内容就回到剪贴板，直接去别处粘贴；单击只是选中。
- **快速放东西**：顶部输入框打字 + 回车，就新增一条。
- **编辑 / 删除**：每条左侧的 `✎` 按钮编辑；选中后按 `Delete` 删除；右键也有菜单。
- **置顶条目**：右键「置顶」，重要线索始终排在最前。
- **搜索**：列表上方的搜索框按关键字过滤。

## 窗口

- **默认位置**：屏幕右下角，不会挡住顶部的浏览器标签/工具栏。
- **会记住位置**：你把窗口拖到哪，下次就在哪。
- **窗口归位**：如果窗口不小心跑到屏幕外找不到了，用 `☰` →「窗口归位」拉回右下角。
- **总在最前**：标题栏「总在最前」切换是否始终悬浮。
- **折叠**：`▁` 折成一条细边，不挡视线；`▔` 展开。
- **透明度**：`◐` 变淡、`◑` 变浓。

## 其他功能

- **密码 / 编码工具箱**：Base64、Hex、二进制、ROT13、凯撒移位、Atbash、Vigenère、摩斯电码、倒序、URL 编解码。
- **菜单（右上角 `☰`）**：设置抓取快捷键、记录当前剪贴板、导出（txt / md）、打开数据目录、窗口归位、清空、退出。
- **自动保存**：内容实时存到本地，关掉重开也不丢。

## 数据位置

- 记录保存在用户目录，不会在桌面生成文件夹：
  `C:\Users\<你的用户名>\AppData\Local\ARG快贴板\data\items.json`
- 同一目录下会自动保留一份上一版备份 `items.bak.json`，万一是主文件损坏也能自动回退。
- 点 `☰` →「打开数据目录」可直接打开该文件夹；备份时复制整个 `data` 文件夹即可。
